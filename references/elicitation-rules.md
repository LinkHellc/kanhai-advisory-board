# 主动询问规则

## 概述

在调用专家之前，检查关键信息是否完备。如缺失，则**先主动询问用户**，再请教专家。

## 触发条件表

| 场景 | 缺失字段 | 询问内容 |
|------|---------|---------|
| 创业咨询 | `projectType` | "您想做什么类型的项目？" |
| 投资建议 | `riskTolerance` | "您的风险承受能力如何？偏好保守、稳健还是激进？" |
| 项目启动 | `constraints` | "有没有时间或预算限制？" |
| 团队管理 | `constraints.teamSize` | "您的团队目前有多大？" |
| 产品咨询 | 目标用户不明 | "您的产品主要面向哪类用户？" |
| 职业规划 | `experienceLevel` | "您在这个领域有多少年经验？" |
| 首次使用 | 无任何 profile | "能否先介绍一下您的背景和目标？" |

## 询问措辞模板

### 初次启动（无任何 profile）

```
您好！我是看海专家顾问团的管理员。为了让各位顾问给您更有针对性的建议，能否先简单介绍一下：

1. 您目前的项目或想解决的问题是什么？
2. 您的目标是什么？
3. 有没有什么时间、预算或资源上的限制？

您可以一次性回答，也可以逐个回答，我会在获取足够信息后再请教各位专家。
```

### 项目类型缺失

```
在给您匹配最合适的专家之前，我想确认一下：您想做的项目具体是哪类？比如是 SaaS 工具、移动应用、还是其他形态？
```

### 风险偏好缺失（投资场景）

```
要给出合理的投资建议，我需要了解一下您的风险承受能力。您是偏好保守（追求稳定）、稳健（平衡）还是激进（能接受较大波动）？
```

### 时间/预算约束缺失

```
为了给出更实际的建议，您方便透露一下这个项目的时间节点和预算范围吗？
```

### 目标不明确

```
您提到的这个目标很广泛。能否细化一下：您希望在 3 个月 / 6 个月 / 1 年内分别达成什么具体成果？
```

### 团队规模缺失

```
您的团队目前有多大？这会影响专家给出的组织架构建议。
```

### 经验水平缺失

```
您在这个领域有多少年的经验？这有助于专家给出更贴合您实际处境的建议。
```

## 阈值设置

通过 `preferences.elicitThreshold` 控制询问的积极程度：

| 阈值 | 行为 |
|------|------|
| `strict` | 仅在核心字段缺失时询问 |
| `moderate` | 核心字段 + 重要上下文缺失时询问（默认） |
| `loose` | 任何可能改善建议质量的字段缺失都询问 |

## 询问优先级

当多个字段缺失时，按以下优先级依次询问：

1. `projectType` — 项目类型
2. `goals` — 目标
3. `riskTolerance` — 风险偏好（投资相关场景优先）
4. `constraints` — 约束条件
5. `experienceLevel` — 经验水平

每次交互只询问 **1-2 个最关键的字段**，避免信息过载。
